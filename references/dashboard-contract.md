# Dashboard contract

The dashboard is an original implementation informed by the public Opulent GTM Intelligence report application's visual direction. The reference repository did not publish a license when checked on 2026-08-05, so this repository does not copy or redistribute its source code.

## Visual idea

Render a compact evidence console rather than a generic analytics template:

- warm near-black field with paper-white type;
- electric cyan, chartreuse, amber, and coral accents;
- a visible dot-matrix/dither language in bars, radar fields, dividers, and status surfaces;
- narrow uppercase metadata, large editorial profile names, and strong reading hierarchy;
- source and status labels in the first viewport;
- restrained motion and a complete reduced-motion path.

## Required views

1. Source-mode banner: live Context extraction, public validation baseline, or blocked.
2. Scope strip: three known URLs, one sponsor firm, zero discovery expansion.
3. Dither coverage bars: professional field coverage by profile.
4. Dither evidence radar: identity, employer, role, sponsor relevance, and extraction receipt dimensions.
5. One dossier route per subject, with clickable LinkedIn and first-party employer sources.
6. Context operation ledger showing planned/executed/blocked state per URL.
7. Sponsor boundary note that prevents individual-level overclaiming.

## Accessibility and responsiveness

- Maintain WCAG-friendly contrast.
- Do not rely on color alone for status.
- Provide chart labels and text summaries.
- Keep focus outlines visible.
- Support 360px-wide screens without horizontal page scrolling.
- Respect `prefers-reduced-motion`.
